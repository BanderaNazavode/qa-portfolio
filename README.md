## Testing Workflow

The following workflow was used during the projects:

**Test Case Design → Test Execution → Test Run → Defect Identification → Bug Reporting**

Test cases were managed and executed in Qase.io. Identified defects were documented in Jira with steps to reproduce, actual results, expected results, environment information, and supporting evidence.
